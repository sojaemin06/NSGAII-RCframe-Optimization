In this study, instead of continuous variables, we adopt a database index, which is a collection of practically manufacturable discrete cross-sections, as the design variable. The overall design variable vector $X$ is defined as follows, based on the number of column groups $n$ and the number of beam groups $m$:

$$
X = [\{C_{id}\}_n, \{R_{dir}\}_n, \{B_{id}\}_m]^T
$$

Here, $C_{id}$ is the index of the column section database, which includes information on the section width ($b$), height ($h$), main reinforcement ratio ($\rho$), and sash spacing ($s$). $R_{dir}$ is a binary variable that determines whether the column is rotated. A value of 0 indicates a 0° rotation with the strong axis along the X-axis, while a value of 1 indicates a 90° rotation with the strong axis along the Y-axis. $B_{id}$ is the index of the beam section database, which includes information on asymmetric reinforcement details and shear reinforcement.
